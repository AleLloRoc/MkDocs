# Introducción

En estas prácticas se han trabajado diferentes herramientas relacionadas con la gestión y colaboración en proyectos mediante **Git y GitHub**. El objetivo principal ha sido conocer el funcionamiento de los repositorios, las ramas y las diferentes formas de trabajar de manera organizada sobre un proyecto.

En la primera práctica se han trabajado las **ramas de Git y las uniones (*merge*)**, aprendiendo a crear y gestionar ramas, realizar cambios independientes y resolver los posibles conflictos que pueden aparecer al fusionarlas.

La segunda práctica se ha centrado en la **colaboración mediante Pull Requests**, aprendiendo a proponer cambios en repositorios de otros usuarios y a integrar las modificaciones realizadas por otros compañeros.

Por último, en la tercera práctica se ha trabajado con **MkDocs y Material for MkDocs** para crear documentación utilizando Markdown y posteriormente publicarla mediante **GitHub Pages**. También se ha utilizado un entorno virtual de Python para instalar y ejecutar las herramientas necesarias.

En conjunto, estas prácticas permiten adquirir una base sobre el uso de Git y GitHub, el trabajo colaborativo y la creación y publicación de documentación técnica.
